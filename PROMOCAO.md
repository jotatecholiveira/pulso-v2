🔒 **Privacidade financeira: por que o Pulso não vende seus dados**

A maioria dos apps financeiros lucra com seus dados. Vendem para anunciantes, parceiros, ou pior.

O **Pulso** funciona diferente:

✅ Seus dados ficam no seu dispositivo
✅ Sem servidor centralizado
✅ Sem cadastro obrigatório
✅ Sem rastreadores de terceiros
✅ Funciona offline
✅ Código fonte aberto

Quando você usa o Pulso, suas finanças são **suas**. Ponto.

Isso é especialmente importante para dados financeiros — gastos, renda, dívidas, investimentos. Ninguém deveria ter acesso a isso sem sua permissão explícita.

- Excel-like spreadsheet with inline editing
- Credit card tracking with bank icons

## 🟠 REDDIT — r/webdev

**Título:** Show r/webdev: Pulso — personal finance PWA built with vanilla HTML/CSS/JS + Firebase

**Post:**
Built a personal finance dashboard as a side project. Pure vanilla JS, no frameworks.

**What it does:**
- Dashboard with Chart.js (pie, bar, line charts)
- Excel-like spreadsheet with inline editing
- Credit card management with bank-specific icons
- Bills payable/receivable tracking
- Family sharing via Firebase Realtime Database
- PWA with offline support
- Dark/light themes, 3 languages

**Interesting technical decisions:**
- Zero build step — direct browser ES6 modules
- Firebase for real-time sync, localStorage as fallback
- DOMPurify for XSS protection
- CSP headers for security
- Custom currency input mask (no library)
- Responsive without Tailwind — pure CSS custom properties

**Live:** https://pulso-5ui.pages.dev

Feedback welcome!
